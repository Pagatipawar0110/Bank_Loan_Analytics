# Bank Loan Analytics

## 📌 Project Overview

This project analyzes bank loan data to understand loan applications, funded amounts, repayment performance, borrower characteristics, and overall loan portfolio performance.

The project demonstrates my practical skills in **SQL, Excel, Power Query, Power BI, and Tableau** for data cleaning, analysis, visualization, and business reporting.

---

## 🎯 Business Objective

The objective of this project is to analyze loan portfolio data and answer important business questions such as:

* How many loan applications were received?
* What is the total funded loan amount?
* What is the average interest rate?
* How are loans performing over time?
* What percentage of loans are performing versus non-performing?
* Which loan characteristics are associated with different repayment outcomes?
* How does loan performance vary across different customer segments?
